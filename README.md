# Walker Pricing Trello Power-Up

Fullscreen pricing tracker for the Walker Tenders board.

## Connector

https://chr155-ai.github.io/walker-tenders-powerup/index.html

## Enable once

1. Open https://trello.com/power-ups/admin
2. New Power-Up on Walker Builders Projects
3. Iframe connector URL: the connector above
4. Capabilities: board-buttons only
5. Icon: icon-dark.png
6. Privacy: https://chr155-ai.github.io/walker-tenders-powerup/privacy.html
7. On Walker Tenders: Power-Ups → Custom → Walker Pricing → Enable

The Pricing button on the board opens the dashboard fullscreen.
